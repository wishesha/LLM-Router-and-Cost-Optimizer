# LLM Router and Cost Optimizer
## Summary
This project is exploration in LLM optimization, specifically Open AI model gpt-5-mini. Deployed through Microsoft Foundry, the goal was to learn how to take the models we are provided with and optimizing them in 3 key ways. 

## Outline
### 1. Token Utilization
A large problem in Generative AI use, especially in industry for businesses, is the cost per token, and the large number of tokens generated by running models and agents.
#### The Fix
I have developed a sliding context window for my LLM. What this does is that instead of resending the entire chat history back to the chatbot every new message, the sliding context window only sends a set limit of the past turns back to the model. This reduces the amount of processing and thus tokens consumed per chat. To solve the problem regarding the loss of prior context due to it not being passed through to the model, I have also implemented a "summary model" which has the task of receiving the past conversation when it grows large enough to have turns that 'fall out' of the context window, and synthesizing them in a short 1-2 sentence summary, passed back to the model, to ensure the overall message and key details of the chat are not lost as the chat grows larger.
